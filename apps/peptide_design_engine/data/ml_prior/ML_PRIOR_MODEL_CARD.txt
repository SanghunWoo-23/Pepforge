Pepforge ML Prior Baseline Model Card
====================================

Model name
----------
pepforge_ml_prior_baseline.joblib

Model type
----------
RandomForestRegressor

Purpose
-------
Lightweight pretrained-lite candidate ranking prior for peptide design.
This is intended to provide an optional ML-assisted ranking signal.
It is not a validated binding-affinity predictor.

Training data
-------------
Bundled synthetic/heuristic interface-inspired peptide feature table.
The training set is designed to mimic broad peptide-interface preferences such as aromatic/anchor enrichment, charge balance, selected motif presence, and excessive hydrophobicity/Cys penalties.

Metrics on internal split
-------------------------
R2: 0.889
MAE: 0.040
Train size: 1287
Test size: 322

Feature names
-------------
length, hydrophobic_ratio, aromatic_ratio, positive_ratio, negative_ratio, charge_norm, anchor_ratio, gly_ratio, pro_ratio, cys_ratio, acidic_basic_balance, motif_RGD, motif_KLV, motif_EEMQR, motif_PXXP_like, motif_LXXLL_like, dipeptide_DE, dipeptide_KK_RR, aromatic_cluster

Limitations
-----------
- Not trained on full PDB protein-peptide complexes.
- Not a substitute for docking, AF3, MD, SPR, ITC, HPLC, LC-MS, or experimental validation.
- Intended only as a weak prior for candidate prioritization.

Future replacement path
-----------------------
Replace peptide_ml_prior_training_data.csv with PDB-derived interface examples, then rerun train_ml_prior_baseline.py.
