# Integration Notes

This package keeps the Colab/Python folder structure while integrating the latest retained features:

- Colab UI with FIX/RANGE length control
- chemistry checkboxes for D-form, noncanonical, linker, tag, label, chemical modification
- motif/constraint style inputs
- docking-ready classification
- surrogate FASTA and manifest export
- optional ML reranking
- optional pseudo-docking input preparation

No Python cache files are included.
