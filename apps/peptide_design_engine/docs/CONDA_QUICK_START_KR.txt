[Peptide Design Engine Conda Quick Start]

1) Anaconda Prompt 실행

2) 압축 푼 폴더로 이동
   cd <압축 푼 폴더 경로>

3) 환경 생성/업데이트
   setup_conda_env.bat

4) GUI 실행
   run_gui_conda.bat

5) CLI 테스트
   run_cli_conda_fast_test.bat

직접 명령:
   conda env update -f environment.yml --prune
   conda activate peptide_engine
   python Python\desktop_gui.py
