# Icon transparency update

## 수정 내용

`PeptideDesignEngine_Icon.png`와 `PeptideDesignEngine_Icon.ico`의 원형 로고 바깥 배경을 투명 처리했습니다.

포함 파일:

```text
assets/PeptideDesignEngine_Icon.png
assets/PeptideDesignEngine_Icon.ico
assets/PeptideDesignEngine_Icon_TRANSPARENT.png
```

이제 바탕화면, 시작 메뉴, 설치 파일 아이콘에서 원 바깥 검정 배경이 보이지 않도록 구성했습니다.
