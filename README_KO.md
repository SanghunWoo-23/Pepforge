# Pepforge 사용 설명서

## 1. Pepforge 실행

설치 후 바탕화면 아이콘 또는 시작 메뉴에서 Pepforge를 실행한다. 소스 모드로 테스트하려면 `Pepforge` 폴더에서 `RUN_SOURCE_DEV.bat`를 실행하거나 `python main_launcher.py`를 실행한다.

메인 런처에는 다음 항목이 있다.

1. Hot Spot Finder
2. Peptide Design Engine
3. SPPS Planner
4. Workflow Mode

각 모듈은 독립적으로 사용할 수 있고, 필요하면 Workflow Mode로 연결해서 사용할 수 있다.
