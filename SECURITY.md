# Security and Private-Data Reports

Do not attach credentials, proprietary sequences, private laboratory records, customer data, or unpublished results to a public issue.

For an ordinary reproducible software bug, open a GitHub issue using the supplied template and use a minimal synthetic input. Remove local paths, names, tokens, and confidential output first.

If a published file appears to expose a credential or private dataset, avoid reposting its contents. Contact the repository owner privately through the address in `CITATION.cff`, identify the affected path, and rotate any exposed credential immediately.
