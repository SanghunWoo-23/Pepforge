Release date: 2026-10-08

1. 이번 릴리스의 목적

UI Polish R3는 V5의 scientific core를 새로 확장하는 버전이 아니라, 실제 Windows 사용 과정에서 확인된 마지막 desktop workflow 문제를 정리하는 릴리스입니다.

이번 릴리스의 핵심은 두 가지입니다.

1. Structure & Docking Studio의 스크롤/레이아웃을 일반적인 분석 프로그램 방식으로 교정
2. Pepforge가 실제 SPPS Planner V7.0.0 FINAL R2를 기본 SPPS workspace로 실행하도록 교체



2. Structure & Docking Studio 개선

일반 마우스 휠 스크롤

이제 peptide sequence editor, Entry, Combobox 등 어느 form widget 위에 마우스가 있어도 일반 마우스 휠만 굴리면 전체 Studio 페이지가 위/아래로 이동합니다.

- middle-button pan 제거
- MouseWheel / Button-4 / Button-5 지원
- PageUp / PageDown / Home / End 지원

scrollbar drag 시 화면이 늘어나는 문제 수정

기존 구조에서는 scrollable Canvas 내부에 resizable PanedWindow가 들어가면서 Windows에서 geometry feedback이 발생할 수 있었습니다.

R3에서는:

- outer Studio = vertical Canvas
- inner page width = viewport width
- inner page height = natural content height
- results = normal stacked sections
- peptide sequence = 자체 horizontal scrollbar
- chemistry table = 자체 horizontal/vertical scrollbar

구조로 변경했습니다.

따라서 오른쪽 scrollbar thumb를 빠르게 이동해도 outer page width가 content requested width에 의해 다시 커지지 않습니다.



3. SPPS Planner V7 FINAL R2 실제 통합

이전 Pepforge는 launcher에서 SPPS Planner를 열어도 내부 호환 controller가 실행될 수 있었습니다.

R3에서는 제공된 SPPS Planner V7.0.0 FINAL R2 Public runtime을 Pepforge 내부에 독립 runtime으로 포함하고, source 실행 시 해당 runtime을 별도 process로 직접 실행합니다.

확인된 UI:

- SPPS Planner V7.0.0 Final
- Project Manager
- Batch Manager
- V7 R2 Add/Edit peptide workflow
- large-workspace layout

Pepforge → SPPS workflow handoff는 environment 값으로만 전달하며 SPPS controller 자체를 monkey patch하지 않습니다.

5. V5 scientific claim boundary

R3는 UI/통합 릴리스이며 scientific claim을 승격하지 않습니다.

- Native docking score ≠ measured affinity
- Native docking score ≠ ΔG / Kd
- Contact geometry ≠ biological activity
- RMSD stability ≠ functional validation
- Native Mechanics ≠ production MD
- Predicted structure ≠ experimental structure



6. V5 종료와 V6 전환

V5의 역할은 다음으로 동결합니다.

> Peptide design → structure preparation → native docking → interaction/mechanics/trajectory review → SPPS planning을 하나의 검증 가능한 local workflow로 완성한다.

V6에서는 V5 workflow를 보존하고, benchmark 기반 search/scoring/ranking 정확도와 uncertainty/OOD, modified chemistry parameterization, GPU/production-MD handoff를 고도화합니다.
