# RCSB PDB Search / Fetch User Guide

## Purpose

Find a target protein structure from RCSB PDB and use it directly as the Docking Workbench target.

## Search examples

```text
1CRN
insulin receptor
albumin
MKWVTFISLLFLFSSAYSR...
```

## Workflow

1. Open Docking Workbench.
2. Enter a PDB code, protein name/title, or sequence.
3. Use `auto` mode unless you need a specific mode.
4. Click `Search RCSB`.
5. Select a result.
6. Choose `pdb` or `cif`.
7. Click `Fetch selected to Target`.
8. Run the Docking Workbench workflow.

## Notes

RCSB search requires internet access. Downloaded structures still require scientific review, including chain selection, biological assembly, missing residues, ligands, cofactors, waters, and experimental quality.
