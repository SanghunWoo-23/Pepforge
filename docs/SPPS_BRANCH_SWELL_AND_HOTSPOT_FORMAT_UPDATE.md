# SPPS Branch / Resin Swell / Hotspot Format Update

This package adds a visible Branch mode block to the SPPS Planner while preserving linear mode as the default. Branch mode appends a branch deprotection block and branch arm coupling rows after the main linear plan. The planner also adds an explicit resin swell operation before loading. The swell solvent follows the loading solvent family: DCM for 2-CTC/trityl resin and DMF for amide/Wang/Rink-type resin.

Hot Spot Finder output uses a monospaced display and wider fixed-width fields so hotspot rows align more cleanly.
