Pepforge Feature Differentiation and Tool Comparison
====================================================

1. Core Positioning
-------------------
Pepforge is not only a peptide generator. It is a workflow suite connecting:

    sequence hotspot analysis
    peptide candidate design
    motif/linker/chemistry constraint handling
    SPPS synthesis planning
    CSV/XLSX documentation

This makes it different from single-purpose tools.

2. Compared with sequence-analysis-only tools
---------------------------------------------
Sequence-analysis tools may identify conserved regions, local motifs, or physicochemical patterns. Pepforge adds downstream candidate design and SPPS planning, so the output does not stop at interpretation.

3. Compared with peptide-design-only tools
------------------------------------------
Many design tools generate candidate sequences and scores. Pepforge adds:

    motif placement ON/OFF
    fixed motif positions
    random non-overlapping motif placement
    linker/terminal chemistry controls
    SPPS planning after design
    workflow/project tracking

4. Compared with synthesis calculators
--------------------------------------
SPPS calculators may estimate reagents or solvent usage. Pepforge connects synthesis planning to upstream hotspot/design decisions, making candidate-to-synthesis traceability possible.

5. Special Features
-------------------
- Standalone Mode and Workflow Mode.
- Complete bundled data/templates/examples retained in this edition.
- Motif placement parser supports comma, slash, semicolon, and newline separators.
- Position system is N-terminal 1-based.
- EXE-ready and installer-ready Windows distribution.
- English and Korean documentation.
- Future ML-ready synthesis logging direction.

6. Scientific Caution
---------------------
Pepforge should be described as a research-support workflow suite, not as a validated peptide discovery platform. It supports hypothesis generation, candidate organization, and synthesis planning, but does not replace experimental validation.
