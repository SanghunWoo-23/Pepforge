Pepforge Password Setup Guide
==============================

1. Current Protected Beta Temporary Admin Passphrase
---------------------------------------------------

    PF-Beta-Admin-2026-Lavender-Molecule-47Q!

This passphrase is for the protected beta scaffold only. It is temporary and should be rotated before wider distribution.

2. What the password currently protects
---------------------------------------
The protected beta package includes a security scaffold:

    security/admin_auth.py
    security/setup_admin_hash.py
    security/admin_hash.json
    security/protected_pack.py

The password is not stored as plain text in admin_hash.json. Instead, PBKDF2-SHA256 hash data is stored.

3. How to change the admin passphrase
-------------------------------------
Open a command prompt inside the Pepforge folder and run:

    cd security
    python setup_admin_hash.py

Then enter the new passphrase twice.

The script will recreate:

    security/admin_hash.json

Only the hash is stored. The raw passphrase is not stored by the script.

4. Recommended passphrase style
-------------------------------
Use a long passphrase, not a short password.

Good example style:

    PF-Beta-Admin-2026-Lavender-Molecule-47Q!

Recommended rules:

- 20+ characters
- include letters, numbers, and symbols
- avoid personal names or obvious lab names
- do not reuse GitHub tokens or real account passwords

5. Important distribution rule
------------------------------
Do not upload these owner-only files to a public GitHub repository:

    OWNER_ADMIN_PASSPHRASE_NOTE.txt
    private keys
    real protected data packs
    internal lab data

6. How to use protected data pack helper
----------------------------------------
The package includes:

    security/protected_pack.py

It can encrypt or decrypt a file using a passphrase-derived key. This is a scaffold for future protected internal data distribution.

7. Security limitation
----------------------
This is beta-level local protection. It is not commercial DRM and does not prevent a determined analyst with full local access. For strong protection, do not ship sensitive data at all, or use a private server/API.
