Pepforge User Manual
====================

1. Launching Pepforge
---------------------

For development or local testing, run:

    RUN_SOURCE_DEV.bat

For distribution, build the installer by running:

    INSTALL_BUILD_TOOLS_AND_BUILD.bat

After a successful build, the installer is located at:

    installer\output\Pepforge_Setup_v0.1.0.exe

Installers place Pepforge under:

    C:\Users\<user>\AppData\Local\Programs\Pepforge

A desktop shortcut is created by default.


2. Main Launcher
----------------

The launcher provides access to:

- Hot Spot Finder
- Peptide Design Engine
- SPPS Planner
- Workflow Mode

Use standalone mode when you want to run one module independently. Use workflow mode when you want to connect hotspot selection, peptide design, and SPPS planning through shared project files.


3. Hot Spot Finder
------------------

Purpose:
Hot Spot Finder identifies residue positions that may be prioritized for downstream peptide design.

Basic steps:

1. Open Hot Spot Finder.
2. Load or paste a FASTA/text sequence.
3. Choose window/overlap/top-N settings if needed.
4. Run analysis.
5. Review the Hot spots table.
6. Open the output folder or use the saved CSV.

Displayed format:

    rank | record | sequence number/amino acid | score | confidence | reason

Example:

    1 | target | 15/R | 0.82 | high | positive/charged; polar

The displayed output intentionally focuses on calculated hotspot entries only.


4. Peptide Design Engine
------------------------

Purpose:
The design engine generates peptide candidates under explicit user-defined constraints.

Basic steps:

1. Open Peptide Design Engine.
2. Enter target sequence(s).
3. Set length mode and generation parameters.
4. In Chemistry / Constraints, enable only the chemistry options you want to apply.
5. Configure motif placement or bridge constraints if needed.
6. Run candidate generation.
7. Review exported candidate tables.

Chemistry toggle behavior:
If a chemistry feature is unchecked, the detailed option group is hidden and that feature is not applied to generated candidates.

Motif placement:

- OFF: no motif placement constraint.
- FIXED: use syntax such as `RGD@1 / EEMQR@4`.
- RANDOM: use syntax such as `RGD / EEMQR`; positions are randomized without overlap.

Motif presets:
The preset control provides common starting templates such as RGD, PXXP-like, LXXLL-like, KLV-like, and custom blank settings. These are starting points and should be reviewed for the biological context.


5. SPPS Planner
---------------

Purpose:
SPPS Planner converts peptide notation into an editable C-term to N-term synthesis plan.

Basic steps:

1. Open SPPS Planner.
2. Enter a sequence, for example:

       Ac-EEMQRR-NH2

3. Enter resin scale, loading, default amino-acid equivalent, modifier equivalent, coupling reagent, catalyst, base, deprotection base, solvent, and repeat settings.
4. Click Parse sequence / build table.
5. Edit the table directly by double-clicking a cell.
6. Review the Material Usage table.
7. Export CSV/XLSX.

Editable columns include:

- unit name,
- unit equivalent,
- unit amount,
- coupling reagent,
- catalyst,
- base,
- deprotection base,
- deprotection ratio,
- solvent,
- solvent-use count,
- repeat count.

Changing equivalent, repeat, or MW-related values recalculates the material usage table.

SPPS exports include:

- editable SPPS plan,
- material usage table,
- step reagent plan,
- ML-ready synthesis log,
- printable synthesis checklist,
- XLSX workbook.


6. Printable Checklist
----------------------

The printable checklist is intended for experimental note-taking. It contains step number, reagent/unit name, equivalent, amount, coupling system, repeat count, date, checked status, and notes.


7. Interpretation
-----------------

Pepforge outputs are computational and planning aids. Hotspot rankings and ML-prior scores are hypothesis-generating signals. SPPS calculations should be reviewed against laboratory SOPs before experimental use.
